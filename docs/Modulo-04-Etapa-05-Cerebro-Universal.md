# Módulo 4 — Etapa 5: Cérebro Universal

A Nexa passa a usar um único motor de decisão para texto e voz.

## Rotas do cérebro

- ação segura no ERP quando existe uma ferramenta correspondente;
- consulta aos dados internos respeitando usuário, escritório e cliente;
- pesquisa online para informações atuais;
- conversa geral para explicações, redações, traduções, resumos, cálculos, planos e orientações;
- esclarecimento quando faltar um dado indispensável.

## Segurança

- nenhuma ação sensível é executada sem confirmação;
- a Nexa não pode afirmar que abriu, alterou, enviou ou concluiu algo sem uma ação executável;
- histórico interno e anotações não são expostos ao perfil Cliente;
- o cliente aberto na tela nunca substitui a identificação segura do cliente citado.

Esta etapa conclui o escopo do Módulo 4. O Módulo 5 reutiliza o mesmo cérebro por voz.
