# Motor Tributário da Nexa

## Princípio
Nenhuma tela deve realizar cálculo tributário diretamente. Todas as regras e cálculos serão centralizados no Motor Tributário.

## v3.4.1 — DNA Empresarial
Esta versão registra o regime, ramo, anexo, Fator R, ISS, datas tributárias e situação da empresa. Ainda não realiza apuração de tributos.

## Segurança
Todo resultado futuro deverá apresentar dados de entrada, regra aplicada, memória de cálculo e aviso para revisão do contador.
