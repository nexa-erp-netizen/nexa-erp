# Módulo 2 — Etapa 4: Planejamento Anual

## Entrega

- Geração das ações mensais do ano por cliente.
- DAS para MEI e Simples Nacional.
- Conferência do PGDAS-D para empresas do Simples.
- Apuração mensal para Lucro Presumido e Lucro Real.
- Honorários mensais e recibos condicionados ao pagamento.
- Conferência mensal de documentos.
- Parcelamentos futuros com controle da sequência das parcelas.
- Persistência local do status de cada ação.
- Integração das ações próximas do vencimento com o Assistente do Dia.

## Observação

O planejamento é uma agenda operacional. Os vencimentos e obrigações devem ser revisados pelo contador conforme o perfil real de cada empresa e a legislação aplicável.
